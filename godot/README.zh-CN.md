# PokéSurvivor — Godot 4.7 移植版（中文说明）

[English](README.md)（完整技术细节：各阶段实现了什么、与网页版逐项对照的检查、性能笔记，都在英文版里）

把浏览器版游戏（`../js`，原生 JavaScript + Canvas 2D）移植到 **Godot 4.7.1 / GDScript**。
**以 JS 代码为准**：移植规格见 [`docs/PORTING.md`](docs/PORTING.md)，与网页版逐项对照见
[`docs/PARITY.md`](docs/PARITY.md)。

**当前状态**：已完成第 0–5 阶段，包括：
- 核心玩法、全部战斗内容（所有技能类型、携带道具、全部敌人行为、预警攻击、Boss、寻路、闪光、技能特效）；
- 地图与地形（像素级一致的地面绘制、21 种地形配色和渐变、可破坏物与掉落、液体、天气）；
- 祭坛、泉水、带锁宝箱、陷阱、怪潮、黄金时间、走失的宝可梦、小偷、裂缝和 18 个传说竞技场、羁绊（技能融合）；
- 养成系统（存档、菜单、图鉴、永久强化、扭蛋、任务和成就、设置、全部精灵图）；
- 展示与平台（西班牙语 / 英语 / 简体中文、像素中文字体、手机布局和界面缩放、手柄和键盘导航、安卓返回键、应用图标）。

**只有单人模式**（没有账号、云存档、联机、排行榜）。

## 快速开始

在仓库根目录执行（需要 Node ≥ 18，Godot 4.7.1 在 `/opt/homebrew/bin/godot` 或 `PATH` 里）：

```sh
node tools/export_godot.js                   # 把 JS 数据导出成 godot/data/*.json（只读 js/）
node godot/tools/sync_sprites.js             # 966 种宝可梦的精灵图集 -> godot/assets/pokemon/（不进 git，约 60 秒）
godot --headless --path godot --import       # 第一次导入（新增 class_name 脚本后也要跑）
godot --path godot                           # 开始玩（或者用编辑器打开项目按 F5）
```

## 操作

- **电脑**：WASD / 方向键移动 · 1–4 / Q / E（Tab）切换当前技能（也可以点技能格） · Esc / P 暂停 ·
  升级时 1 / 2 / 3 选卡、R 换一批卡（也可以点卡）。菜单里用方向键 / Tab 移动焦点，Enter / 空格确认，Esc 返回。
- **手柄**：左摇杆移动，LB/RB 切换技能，Start 暂停；所有菜单和卡片都能用十字键或摇杆加 A 操作，B 返回，Y 换卡。
- **触屏（安卓，横屏）**：手指按下的地方出现浮动摇杆（按在界面按钮上除外，大小在 *设置 › 操作* 里调），
  点技能格切换，右上角暂停；安卓**返回键**在对局中暂停、在其他界面关闭当前界面、在主菜单询问是否退出。
  电脑上可以打开编辑器设置 *Input Devices → Pointing → Emulate Touch From Mouse* 用鼠标模拟触屏。

## 调试参数

写在命令最后的 `--` 之后，例如 `godot --path godot -- --autoplay --bot=expert`。

| 参数 | 作用 |
|---|---|
| `--partner=<图鉴号>` | 伙伴宝可梦（默认 4 小火龙） |
| `--seed=<n>` | 地图种子 |
| `--autoplay` | bot 一直玩下去（每局结束自动开新局） |
| `--bot=legacy\|novice\|casual\|expert` | 谁来玩 bot 局（见下面“试玩模拟器”），默认 legacy |
| `--bot-set=k=v,...` | 临时修改某一档 bot 的参数 |
| `--speed=<n>` | 配合 `--autoplay` 快进：每帧跑 n 步模拟，并在终端打印每局成绩 |
| `--god` | 配合 `--autoplay`：不受伤害（满屏 64 个敌人的性能测试） |
| `--touch` · `--fps` | 强制触屏界面 · 显示帧数 |
| `--lang=es\|en\|zh` | 这次运行用的语言（不保存） |
| `--ui-scale=<n>` | 手机界面缩放（例如 1320×608 窗口加 1.5 = 目标手机的一半大小） |
| `--save=<路径>` | 指定存档文件 |
| `--import=<文件>` · `--import-ui=<文件>` | 导入网页版存档（直接导入 / 像玩家一样通过设置界面导入） |
| `--autoshot=<目录>` | 视觉检查：标题 → bot 玩一局 → 截图 → 退出（`--p2` / `--p3a` / `--p3b` 是各阶段的专项截图） |
| `--metashot=<目录>` | 把所有菜单界面走一遍并截图 |

还有一批方便测试的参数（`debug/autoshot2.gd`，`tests/sim_smoke.gd` 也认）：`--learn=id,id`（开局学这些技能）、
`--move-lvl=<1-5>`、`--evolve`、`--boss-at=<秒>` / `--boss-gap=<秒>`（Boss 出现时间）、`--force-shiny=<n>`、
`--item=<id>`、`--cycle`（旧 bot 每 6 秒换一次技能）、`--start-t=<秒>`（从某个时间点开局）、
`--event=horde,gold,lost,thief`、`--event-at=<秒>`、`--rift-at=<秒>`、`--rift-type=<属性>`、`--bonds=<n>`、`--seek`。
详细说明见英文版。

**bot 局和截图局（`--autoshot`、`--autoplay`、`--metashot`）用的是内存里的新存档，不会写入磁盘**，也不会推进任务和成就。

## 试玩模拟器

用来回答“这个游戏难不难、玩家能玩多久、要肝多久”这类设计问题：让**像真人一样玩的 bot** 在无窗口模式下
大量地玩，然后统计数字。

### 四种 bot（`debug/bot.gd`）

| 档位 | 是谁 | 反应时间 | 操作 | 漏看危险 |
|---|---|---|---|---|
| `legacy` | 原来的测试 bot：画大圈、躲开靠近的敌人、捡经验，只用第一个技能。单元测试、性能测试、截图工具都用它（默认） | — | — | — |
| `novice` 新手 | 不会绕圈风筝，爱捡东西，学了新技能就一直用新的，选卡看哪张“看起来厉害” | 0.40 秒 | 键盘 8 方向 | 25% |
| `casual` 普通 | 会绕着怪群走，用等级最高的技能，会换卡 | 0.27 秒 | 键盘 8 方向 | 10% |
| `expert` 高手 | 走位最细，看情况换技能（打 Boss 用单体、怪多用范围），安全时叠 buff，会提前拿技能进化需要的属性 | 0.18 秒 | 摇杆 16 方向 | 2% |

三档“像真人”的 bot 是这样玩的：
- **反应时间**：新出现的预警圈、敌人子弹、冲锋怪的蓄力，要过一段反应时间才会“看见”，偶尔还会完全漏看一个；只盯着最近的 N 个敌人。
- **走位**：每秒决策几次。把每个方向往后 0.5–1 秒的情况打分，考虑的内容有：
  - 敌人会走到哪（快跑怪会像游戏里一样预判你的位置）；
  - 预警区域、子弹轨迹；
  - 墙、岩浆、陷阱；
  - 怪群密度，会不会被堵在墙角。
  
  会**绕着怪群兜圈子**，不是直线逃跑。
- **打法**：和怪保持当前技能合适的距离；**火线被石头、树、墙挡住时会换位置**（子弹穿不过它们）；捡没有怪站着的经验。
- **地图**：裂缝出现时赶过去；会去用祭坛，受伤时去泉水；会**守在带锁宝箱旁边直到打开**（怪太多或血太少就放弃）。
- **选卡和技能**：按这档玩家的习惯选卡、换卡、切换技能。

它们的随机性来自自己的随机数生成器（用地图种子初始化），不会影响游戏本身的随机数，所以**同一个种子加同一档 bot，结果永远完全一样**（单进程和多进程并行也一样）。

**调参数**：所有数值都在 `Bot.PROFILES` 里，`--bot-set` 可以只在这一次运行里改掉，例如
`--bot-set=react=0.35,margin=20,chest=3/6`。可以改的参数：

| 参数 | 意思 |
|---|---|
| `react` | 反应时间（秒） |
| `think` | 两次决定方向之间的间隔（秒），中间一直按着同一个方向 |
| `dirs` | 8 = 键盘，16 = 摇杆 |
| `lapse` | 完全漏看某个危险的概率 |
| `noise` | 操作误差（弧度） |
| `attention` | 同时盯着最近的几个敌人（Boss 总是盯着） |
| `see` | 多远能注意到危险和掉落物 |
| `margin` | 和敌人身体保持的安全距离 |
| `horizon` | 往后看多少秒 |
| `crowd` | 多讨厌走进怪堆 |
| `tangent` | 多喜欢绕圈风筝 |
| `greed` | 经验和掉落物的吸引力 |
| `seek` | 多远以内会去祭坛 / 泉水 / 带锁宝箱 |
| `chest` | `安全/放弃`：身边敌人不超过“安全”数才去开箱，超过“放弃”数就走 |
| `aim` | 多在意火线不被挡住（0 = 不在意） |
| `switch` | `stay` 一直用当前技能 · `best` 用等级最高的 · `smart` 看情况 |
| `cards` | 选卡习惯：`novice` / `casual` / `expert` |
| `buffs` | 安全时是否叠 buff 技能 |
| `reroll` | 手牌不好时是否换卡 |
| `shop` | 养成模式里怎么花钱：`cheapest` 总买最便宜的 · `casual` / `expert` 按性价比 |

### 批量试玩（`tests/sim_play.gd`）

```sh
godot --headless --path godot --script res://tests/sim_play.gd -- --bot=novice,casual,expert --runs=100 --lang=zh
```

每档玩 `--runs` 局（默认 20；每档用同一批地图种子，比较才公平），**每局一直玩到宝可梦倒下为止**。
同时开多个无窗口的 Godot 进程并行跑（默认 CPU 线程数减 2，最多 12 个，比单进程快约 7 倍），每 5 秒打印一次进度。

| 参数 | 作用 |
|---|---|
| `--bot=a,b,c` | 跑哪几档（`legacy` / `novice` / `casual` / `expert`） |
| `--runs=<n>` | 每档几局 |
| `--seed=<n>` | 第一个地图种子（之后 +1、+2…） |
| `--jobs=<n>` | 并行进程数；`--jobs=1` 在当前进程里跑 |
| `--partner=<图鉴号>` | 伙伴宝可梦 |
| `--upg=<0..1>` | 永久强化买了多少（每项最高等级的比例；0 = 新账号，1 = 全满） |
| `--max=<秒>` | 每局最多玩多久（默认 0 = 玩到倒下；另有 4 小时安全上限） |
| `--lang=zh` | 中文报告 |
| `--csv=<文件>` | 每局一行导出成表格 |
| `--verbose` | 打印每一局的明细 |
| `--bot-set=k=v,...` | 临时改 bot 参数（见上表） |
| `--trace=<秒>` | 每隔几秒打印一行状态（血量、等级、附近敌人数、当前技能、方向），配合一档、`--runs=1` 使用 |
| `--prof` | 每帧时间：bot 决策 vs 游戏模拟（以及模拟里各部分） |

报告内容（每档一份）：
- **坚持时间**：中位数 / 平均 / 最短 / 最长，以及时长分布（不到 1 分钟、1–2 分钟……10 分钟以上各几局）；
- **最好的一局**：种子、坚持时间、等级、击杀、宝可梦币；
- **击杀**、**宝可梦币**：平均 / 最多 / 所有局合计；
- **永久强化**：按这个收入，把这只宝可梦的强化全部点满要多少局、多少小时；
- 每局等级、打赢 Boss 数，第一个 Boss（3 分钟）见到和打赢的比例，1 / 3 / 5 / 10 分钟时的等级；
- **掉血来源**和**致命一击来源**（见下面的说明）；
- **走位**：每秒换几次方向、站着不动的比例、离最近敌人的平均距离；
- **地图**：开带锁宝箱、用祭坛、泉水回血、触发陷阱、裂缝出现 / 进入 / 打赢的次数；
- **射击**：有目标在射程内时火线被挡住的时间比例，撞墙 / 打在石头上的子弹比例。

### 养成模式（`--campaign`）：账号会成长，不再每局从零开始

```sh
# 开始养成，或者接着上次的进度继续（同一个存档目录 = 接着玩）
godot --headless --path godot --script res://tests/sim_play.gd -- --campaign=100 --accounts=4 --save-dir=user://accounts --lang=zh
# 只看存档账号的报告，不玩新局（模拟还在跑的时候也能看）
godot --headless --path godot --script res://tests/sim_play.gd -- --campaign=0 --accounts=4 --save-dir=user://accounts --lang=zh
```

- 每档 `--accounts` 个账号（默认 4 个，各占一个进程）。每个账号像新账号一样**拿 500 币开局、没有强化**，连续玩 `--campaign` 局。
- 每局结束，赚到的宝可梦币进钱包，然后**按这档玩家的习惯买伙伴的永久强化**（`Bot.shop`）：新手总买最便宜的；普通和高手按“性价比”挑（权重在 `Bot.SHOP_W`），也会攒钱买“开局 2 个技能”；买了“禁用”就禁掉不打伤害的 buff 技能。下一局带着这些强化继续打。
- `--save-dir=<目录>` 把每个账号存成 `<目录>/<档位>_<编号>.json`（钱包、强化等级、玩了几局、总游戏时长、下一局的种子、每一局的记录）。**每局结束都会保存**，用同一个目录再跑一次就接着玩。
  `user://accounts` 在 macOS 上是 `~/Library/Application Support/Godot/app_userdata/PokeSurvivor/accounts`。
- 各档的账号 k 玩的是同一批地图，比较才公平。

报告是每档的**成长曲线**：
- 在第 1、5、10、20、30、50、75、100… 局时：累计游戏时长、强化进度（4 万币花掉了多少）、平均和最长坚持时间、每局收入、见到 Boss 的比例；
- **第一次坚持到 3 / 5 / 10 分钟**、**强化全部点满**分别是第几局、玩了几小时（几个账号的中位数）；
- 账号 1 最先买了哪些强化。

还没有模拟的：扭蛋（换别的宝可梦）、每日 / 每周任务、成就奖励。bot 的技术水平也不会随着局数提高（真人会越玩越熟练）。

### 开窗口看 bot 玩

```sh
godot --path godot -- --autoplay --bot=expert --speed=4
```

一局接一局地玩；`--speed=<n>` 是快进倍数（每帧跑 n 步模拟，步长不变，所以只是变快，玩法完全一样）。
每局结束会在终端打印：坚持时间、等级、击杀、宝可梦币、目前最好的一局。

### 掉血来源和致命一击是怎么记的

每次掉血都记下来源（`Player.dmg_log`，最后一下记在 `Player.last_hit`），只是记账，不改变游戏：

| 记录 | 中文报告 | 意思 |
|---|---|---|
| `touch:<行为>` | 撞击·<怪的类型> | 被敌人身体撞到 |
| `boss` | Boss | 被 Boss 身体撞到 |
| `shot` | 子弹 | 敌人的子弹 |
| `hazard:<谁>` | 预警攻击·<谁> | 先在地上出现预警的攻击（Boss、射线怪、地面圈怪、自爆怪、跳跃怪） |
| `trap` · `lava` · `weather` | 陷阱 · 岩浆 · 天气 | 地图造成的伤害 |

怪的类型：`chase` 追击怪 · `runner` 快跑怪（每档一只，最快、会预判你的位置）· `charger` 冲锋怪 ·
`jumper` 跳跃怪 · `bomber` 自爆怪 · `beamer` 射线怪 · `zoner` 地面圈怪 · `fan` 扇形弹怪 · `ranged` 远程怪 ·
`tank` 坦克怪 · `healer` 治疗怪 · `shielder` 护盾怪 · `summoner` 召唤怪。

## 目录结构（简要）

```

core/     通用工具、数据表、精灵图、设置、音效、存档、任务成就、扭蛋、永久强化、多语言
sim/      和画面无关的游戏模拟：玩家、敌人和 Boss AI、刷怪、战斗、子弹、预警攻击、寻路、道具、
          掉落、升级卡、技能、属性相克、地图、天气、祭坛宝箱陷阱、事件、裂缝
render/   画面：世界、技能特效、伤害数字、地面和液体、地图物件、天气
ui/       界面：HUD、触屏、升级卡、菜单、图鉴、强化、扭蛋、任务、设置、性格测试、结算
```
